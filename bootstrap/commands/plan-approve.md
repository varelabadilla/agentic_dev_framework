# /plan-approve — Confirm the Current Implementation Plan

## Usage

`/plan-approve`

Run this after reviewing the plan generated by `/plan phase-N` and any adjustments made with `/plan-adjust`.

## Process

1. Check that `.runbook/plan.md` exists. If it does not, inform the user:
   "No plan found in .runbook/. Run /plan phase-N first."
   Stop.

2. Read `.runbook/plan.md` in full.

3. Append to `activity.log`:
   `[{timestamp}] /plan-approve: Plan approved by user`

4. Inform the user:
   "Plan approved and locked. Run /execute phase-N to begin implementation."

5. **Do NOT execute any implementation steps.**
   `/plan-approve` only confirms. `/execute` implements.
