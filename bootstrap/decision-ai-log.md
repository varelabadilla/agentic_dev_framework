## How to Use

At the end of a Claude.ai planning session where significant decisions were made:

1. Ask Claude.ai to summarize the key decisions from the session
2. Copy the summary into a new entry below using the format shown
3. Download this file and commit it to the repository
4. Re-upload to the Claude.ai project to keep the planner's context current
