# /adjust — Request Changes to the Current Plan

## Usage

`/adjust {inline text describing changes}`
`/adjust {path-to-adjustments-file}`

Examples:
- `/adjust Remove step 3 and add a migration step before step 4`
- `/adjust .claude/tmp/plan-adjustments.md`

Run this after reviewing the plan generated by `/plan phase-N`.

## Process

1. Parse `$ARGUMENTS` to determine input type:
   - If the argument is a file path that exists on disk → read that file in full as the adjustments source
   - If the argument is inline text → use that text directly as the adjustments description
   - If the file path does not exist → inform the user and stop

2. Check that `.runbook/plan.md` exists. If it does not, inform the user:
   "No plan found in .runbook/. Run /plan phase-N first."
   Stop.

3. Read `.runbook/plan.md` in full.

4. Apply each adjustment to `.runbook/plan.md`:
   - Modify only what the adjustment specifies
   - Preserve all other content, structure, and section headings
   - If any adjustment is ambiguous, ask for clarification before editing that item — apply unambiguous ones first

5. Append to `activity.log`:
   `[{timestamp}] /adjust: Plan updated — {brief summary of change}`

6. Present the updated plan to the user and ask:
   "Plan updated. Review the changes above and:
   - Run **/approve** to confirm the plan
   - Run **/adjust** to continue refining
   - Run **/plan-discard** to discard and start over"

7. **Do NOT execute any implementation steps.**
